# 바다거북 스프

예·아니오 질문만으로 이야기 뒤에 숨은 사정을 맞히는 상황 추리 게임입니다.
한 문제는 **여러 장(章)으로 이어지는 한 시간짜리 이야기**입니다.
`index.html` 한 파일로 되어 있고, 빌드나 설치가 필요 없습니다.

- **바로 플레이:** https://claude.ai/artifact/7ZgUfpDt8tGEBi67SmCatu
- **로컬 플레이:** `index.html`을 브라우저로 열면 됩니다.

## 진행 방식

1. 1장 장면을 읽습니다. 매운맛은 세계관 문서가, 순한맛과 보통맛은 배경 정보가 함께 열립니다.
2. 진행자에게 예·아니오로 답할 수 있는 질문을 합니다.
3. 그 장의 핵심 단서를 모두 밝히면 그 장의 정답이 열리고 다음 장이 시작됩니다. 질문으로 하나씩 밝혀도 되고, "추리 제출"로 한 번에 밝혀도 됩니다.
4. 마지막 장까지 풀면 완식입니다. 막히면 그 장을 넘길 수 있고 이때는 완주로 기록됩니다. 전체를 포기하면 남은 정답과 결말을 모두 보지만 기록은 남지 않습니다.

## 메뉴판

메뉴판은 위에서 아래로 표지, 사용방법, 오늘의 추천, 맛별 전체 메뉴, 진행자 설정, 푸터 순서로 읽힙니다.

- **오늘의 추천:** 날짜에 따라 매일 바뀝니다. 날짜로 시작 위치를 정한 뒤, 이미 다 푼 문제는 건너뛰고 다음 문제를 고릅니다. 표지의 시작 버튼도 이 문제를 엽니다.
- **맛별 전체 메뉴:** 순한맛, 보통맛, 매운맛 순서로 모든 문제가 번호대로 놓입니다.
- **진행자 설정:** AI 진행자와 친구가 진행 중에서 고릅니다. 위쪽 바의 진행자 칩으로도 바로 갈 수 있습니다.
- 위쪽 바의 해·달 버튼으로 밝은 화면과 어두운 화면을 바꿀 수 있습니다.

| 진행자 | 언제 쓰나 | 동작 |
| --- | --- | --- |
| AI 진행자 | claude.ai에서 열었을 때 | Claude가 정답을 보고 예 / 아니오 / 상관없음 / 부분적으로 / 다시 질문 중 하나로 답하고, 추리가 그 장의 핵심 단서를 몇 개 맞혔는지 판정합니다. 질문과 추리마다 보는 사람의 Claude 사용량을 씁니다. |
| 친구가 진행 | 어디서나 (로컬 파일 포함) | 한 사람이 진행자 노트로 정답을 몰래 읽습니다. 질문에는 예 / 아니오 / 상관없음 / 부분적으로 버튼으로, 추리에는 맞혔어요 / 거의 / 아직 버튼으로 답하고, 밝혀진 단서에 표시합니다. |

## 시간과 별점

- 기준 플레이 시간은 문제마다 다르며(40~80분, 5분 단위) 메뉴판에 적혀 있습니다. 블라인드 플레이테스트에서 장마다 몇 번째 질문에 풀렸는지와 읽기 분량을 재어 사람 기준으로 환산한 값입니다. 화면 위 시계는 문제 화면을 보고 있을 때만 흐르고, 브라우저에 저장돼 이어서 할 수 있습니다.
- 별점은 `걸린 분 + 힌트 × 5 + 틀린 추리 × 3 + 넘긴 장 × 20`으로 셉니다. 기준 시간 이하면 ★★★, 기준의 1.5배 이하면 ★★, 그 위는 ★입니다.

## 난이도

| 난이도 | 구성 |
| --- | --- |
| 순한맛 | 3장, 핵심 단서 8~11개. 장마다 한 번씩 비틀면 풀리는 이야기 |
| 보통맛 | 3장, 핵심 단서 10~11개. 마지막 장이 앞의 장을 뒤집는 속임수 |
| 매운맛 | 4장, 핵심 단서 14~17개. 세계관 문서가 딸린 장편 |

## 문제 데이터

지금 들어 있는 문제는 열 편입니다. 매운맛 네 편(바다거북 스프, 안개 종의 섬, 청운사진관, 불 하나의 밤), 보통맛 세 편(벽 너머의 칠호, 지도에만 있는 마을, 안개 위의 거인), 순한맛 세 편(702호의 출근 인사, 소피아의 고갯짓, 두 번째로 들어온 남자).

문제는 `index.html` 안의 `<script type="application/json" id="puzzle-data">` 블록에 JSON 배열로 들어 있습니다. 배열 순서가 메뉴 번호가 되고, 오늘의 추천도 이 순서를 따라 돌아갑니다.

```jsonc
{
  "id": "turtle-soup", "level": "hot", "title": "...", "teaser": "메뉴 한 줄", "minutes": 60,
  "world": { "intro": [], "places": [{ "name": "", "desc": "" }], "people": [{ "name": "", "role": "", "desc": "" }],
             "timeline": [{ "when": "", "what": "" }], "glossary": [{ "term": "", "desc": "" }] },
  "secret": ["숨은 설정 (진행자와 결말 화면에만)"],
  "chapters": [
    { "title": "", "scene": ["장면 문단"], "question": "이 장의 질문", "truth": ["정답 문단 (장을 풀면 열림)"],
      "keys": ["핵심 단서 (모두 밝히면 장 해결)"], "hints": ["힌트1", "힌트2", "힌트3"] }
  ],
  "epilogue": ["결말 문단"]
}
```

풀이 기록과 경과 시간은 브라우저 `localStorage`에만 저장됩니다.
