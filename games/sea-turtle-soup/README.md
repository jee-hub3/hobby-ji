# 바다거북 스프

예·아니오 질문만으로 이야기 뒤에 숨은 진상을 맞히는 상황 추리 게임입니다.
`index.html` 한 파일로 되어 있고, 빌드나 설치가 필요 없습니다.

- **바로 플레이:** https://claude.ai/artifact/7ZgUfpDt8tGEBi67SmCatu
- **로컬 플레이:** `index.html`을 브라우저로 열면 됩니다.

## 진행 방식

| 진행자 | 언제 쓰나 | 동작 |
| --- | --- | --- |
| AI 진행자 | claude.ai에서 열었을 때 | Claude가 진상을 보고 예 / 아니오 / 상관없음 / 부분적으로 중 하나로 답하고, 제출한 추리가 핵심 단서를 몇 개 맞혔는지 판정합니다. 질문할 때마다 보는 사람의 Claude 사용량을 씁니다. |
| 친구가 진행 | 어디서나 (로컬 파일 포함) | 한 사람이 "진행자 노트"로 진상을 몰래 읽고, 다른 사람들의 질문에 버튼으로 답합니다. |

로컬 파일로 열면 Claude에 연결할 수 없어서 자동으로 "친구가 진행" 모드가 됩니다.

## 구성

- 문제 12개: 순한맛 4, 보통맛 5, 매운맛 3 (간판 메뉴 "바다거북 스프" 포함)
- 문제마다 핵심 단서 2~4개와 단계별 힌트 3개가 있습니다. 핵심 단서를 모두 맞히면 "완식"입니다.
- 별점은 질문 수, 힌트 사용, 틀린 추리 횟수로 매깁니다.
- 풀이 기록은 브라우저 `localStorage`에만 저장됩니다.

문제를 추가하려면 `index.html` 안의 `PUZZLES` 배열에 항목을 하나 더 넣으세요
(`story`·`truth`는 문단 배열, `keys`는 완식 판정에 쓰는 핵심 단서, `hints`는 힌트 3개).
