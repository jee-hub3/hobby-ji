# 바다거북 스프

예·아니오 질문만으로 이야기 뒤에 숨은 진상을 맞히는 상황 추리 게임입니다.
한 문제는 **여러 장(章)으로 이어지는 한 시간짜리 이야기**입니다.
`index.html` 한 파일로 되어 있고, 빌드나 설치가 필요 없습니다.

- **바로 플레이:** https://claude.ai/artifact/7ZgUfpDt8tGEBi67SmCatu
- **로컬 플레이:** `index.html`을 브라우저로 열면 됩니다.

## 진행 방식

1. 1장 장면을 읽습니다. 매운맛(장편)은 세계관 문서가 함께 열립니다.
2. 진행자에게 예·아니오로 답할 수 있는 질문을 합니다.
3. 그 장의 핵심 단서를 모두 밝히면 진상이 열리고 다음 장이 시작됩니다. 질문으로 하나씩 밝혀도 되고, "이 장 추리 제출"로 한 번에 밝혀도 됩니다.
4. 마지막 장까지 풀면 완식입니다. 막히면 그 장을 넘길 수 있고(완주로 기록), 전체를 포기할 수도 있습니다.

| 진행자 | 언제 쓰나 | 동작 |
| --- | --- | --- |
| AI 진행자 | claude.ai에서 열었을 때 | Claude가 진상을 보고 예 / 아니오 / 상관없음 / 부분적으로 / 다시 질문 중 하나로 답하고, 추리가 그 장의 핵심 단서를 몇 개 맞혔는지 판정합니다. 질문할 때마다 보는 사람의 Claude 사용량을 씁니다. |
| 친구가 진행 | 어디서나 (로컬 파일 포함) | 한 사람이 진행자 노트로 진상을 몰래 읽고, 질문에 버튼으로 답하며, 밝혀진 단서에 표시합니다. |

## 시간과 별점

- 기준 플레이 시간은 **60분**입니다. 화면 위 시계는 문제 화면을 보고 있을 때만 흐르고, 브라우저에 저장돼 이어서 할 수 있습니다.
- 별점은 `걸린 분 + 힌트 × 5 + 틀린 추리 × 3 + 넘긴 장 × 20`으로 셉니다. 60 이하면 ★★★, 90 이하면 ★★, 그 위는 ★입니다.

## 난이도

| 난이도 | 구성 |
| --- | --- |
| 순한맛 | 3장, 핵심 단서 7~8개. 장마다 한 번씩 비틀면 풀리는 이야기 |
| 보통맛 | 3장, 핵심 단서 9~10개. 마지막 장이 앞의 장을 뒤집는 속임수 |
| 매운맛 | 4장, 핵심 단서 12~14개. 세계관 문서가 딸린 장편 |

## 문제 데이터

문제는 `index.html` 안의 `<script type="application/json" id="puzzle-data">` 블록에 JSON 배열로 들어 있습니다. 배열의 첫 문제가 메뉴판의 간판 메뉴가 됩니다.

```jsonc
{
  "id": "turtle-soup", "level": "hot", "title": "...", "teaser": "메뉴 한 줄", "minutes": 60,
  "world": { "intro": [], "places": [{ "name": "", "desc": "" }], "people": [{ "name": "", "role": "", "desc": "" }],
             "timeline": [{ "when": "", "what": "" }], "glossary": [{ "term": "", "desc": "" }] },
  "secret": ["숨은 설정 (진행자와 결말 화면에만)"],
  "chapters": [
    { "title": "", "scene": ["장면 문단"], "question": "이 장의 질문", "truth": ["진상 문단"],
      "keys": ["핵심 단서 (모두 밝히면 장 해결)"], "hints": ["힌트1", "힌트2", "힌트3"] }
  ],
  "epilogue": ["결말 문단"]
}
```

풀이 기록과 경과 시간은 브라우저 `localStorage`에만 저장됩니다.
