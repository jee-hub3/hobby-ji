# 유료 제품까지

## 지금 끝난 것 (0.1 베타)

- 독립 웹 서비스: 정적 페이지 + Cloudflare Worker + D1, 홈 화면 추가(PWA 매니페스트), 공유 미리보기 이미지
- AI 진행자를 운영자 API 키로 제공, 키와 지시문은 서버에만
- 정답 보호: 브라우저에는 열린 장면과 푼 장의 정답만 나감
- 비용 방어: 하루 예산, 기기·IP별 하루 한도, 분당 한도, 비상 스위치
- 지표: 호출별 비용·토큰·응답 시간, 게임 이벤트, 의견 보내기, 관리자 통계 API
- 개인정보 처리방침·이용약관 초안, 진행자 모델 정확도 시험 도구
- 테스트: 엔진 단위 12개, 브라우저 통합 47개, 예산 소진 4개 (가짜 Claude 서버 사용)

## 한 판당 AI 비용 (추정)

질문 판정에 Haiku 5.5(노력 low), 추리 판정에 Sonnet 5.5(medium)를 쓰고 캐시가 맞는다고 본 값입니다.
질문 수는 블라인드 플레이테스트에서 잰 값, 한국어 1글자를 0.8~1.2토큰으로, 1달러를 1,400원으로 계산했습니다.
실제 값은 베타 운영 통계의 `costPerGame`으로 확인하세요.

| 문제 | 맛 | 질문 수 | Haiku+Sonnet | 전부 Sonnet | 캐시 없이 Haiku+Sonnet |
| --- | --- | --- | --- | --- | --- |
| 바다거북 스프 | 매운맛 | 138 | 280~360원 | 1,890~2,550원 | 570~790원 |
| 안개 종의 섬 | 매운맛 | 125 | 270~340원 | 1,730~2,320원 | 520~720원 |
| 청운사진관 | 매운맛 | 100 | 240~310원 | 1,350~1,800원 | 430~590원 |
| 불 하나의 밤 | 매운맛 | 90 | 230~290원 | 1,220~1,620원 | 390~530원 |
| 순한맛·보통맛 | | 50~75 | 160~200원 | 630~1,040원 | 220~320원 |

모델 선택이 가격 구조를 가릅니다. Haiku로 품질이 충분하면 장편 한 편을 3,000원에 팔 때 AI 비용은 12% 안쪽입니다.
질문까지 Sonnet이 필요하면 장편 한 판에 2,000원 안팎이 들어, 판매가를 더 높이거나 질문 수를 묶어 파는 구조가 필요합니다.

## 정식 출시 전에 꼭 할 일

1. **저장소 정리** — 지금 저장소는 공개(MIT)이고, 문제 원문과 정답이 그대로 올라가 있습니다.
   - 유료로 팔 문제는 비공개 저장소로 옮기고, 공개 저장소의 기록에서도 빼는 것이 안전합니다.
   - 이야기 원문의 권리(저작권)를 코드의 MIT 라이선스와 분리해 명시하세요.
2. **진행자 모델 확정** — `eval/run.js`로 시험하고, 베타 질문을 시험 세트에 더해 다시 잽니다.
3. **법적 문서 확정** — 운영자 정보 기입, 전문가 검토.
4. **악용 방어 강화(트래픽이 늘면)** — Cloudflare Turnstile로 새 브라우저 확인, WAF 요율 제한.

## 결제 붙이기 (사업자등록 뒤)

1. 개인사업자 등록, 통신판매업 신고
2. 결제대행사 선택과 심사 (국내 간편결제가 필요하면 국내 PG, 해외 판매가 많으면 판매대행)
3. 계정: 이메일 또는 소셜 로그인. 지금의 익명 ID 기록을 로그인 계정으로 옮겨 붙이는 단계를 넣습니다.
4. 구매 기록 표(`purchases`)와 웹훅 처리, `canPlay()`에서 구매 여부 확인
5. 문제별 `access` 값 지정: 순한맛 1~2편은 'free', 나머지는 상품 코드
6. 환불·청약철회 규정을 약관에 추가 (디지털 콘텐츠는 열람 전 철회 가능 여부를 명시)
7. 가격 실험: 장편 단품, 맛별 묶음, 전체 묶음
